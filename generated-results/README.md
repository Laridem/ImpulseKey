## How to Generate

1. Make sure dev server is running: `npm run dev`
2. Open `generate-results.html` in your browser
3. Click "Start Auto Generation" or individual result buttons
4. Download each PNG when prompted
5. Move downloaded files to this folder

## File Naming Convention

Files should be named: `IMPULSE-{KEY}.png`

Example: `IMPULSE-AGENT.png`, `IMPULSE-SAFE.png`, etc.
