## Lessons Learned

1. **Always test mobile early**: Desktop-first design can create oversized mobile layouts
2. **Tailwind responsive prefixes**: Use `sm:`, `md:`, `lg:` consistently
3. **Text sizing**: Mobile text should be 10-14px base, tablet 14-16px, desktop 16-18px
4. **Button sizing**: Mobile buttons need adequate padding (py-3 min) for touch
5. **Confetti libraries**: `canvas-confetti` provides excellent out-of-box animations
